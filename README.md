## 五、学习与开发环境

- **操作系统**：Linux（Ubuntu26.04LTS）（x86-64）
- **编译器**：`gcc`
- **调试 / 反汇编工具**：
  - `gdb` —— 调试
  - `ImHex` —— 反汇编
- **编辑器**：VS Code

### 编译与运行

```bash
# 编译单个源文件（带调试信息）
gcc -g -Wall 源文件.c -o 输出名

# 示例：编译并运行 Day 1 的找零计算器
cd 1day
gcc -g -Wall 1.c -o 1
./1
```
